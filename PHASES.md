# KrishiMitra AI - Implementation Roadmap & Phases

| Phase | Title | Focus & Core Deliverables | Prerequisites & Dependencies | Effort & Priority |
| :--- | :--- | :--- | :--- | :--- |
| **Phase 1** | **Dynamic Data Pipeline & Fix Missing Rates** | • Remove hardcoded 9-crop filter; dynamically auto-register any crop (Apple, Banana, etc.) and mandi into SQLite on arrival.<br>• Pre-seed top 50 crops and Gujarat/Maharashtra APMCs.<br>• State-wise paginated sync from data.gov.in.<br>• Autocomplete/search dropdowns. | Existing `DATAGOV_API_KEY` (Self-contained, zero external onboarding) | Immediate / Urgent (Fixes Apple in Gujarat bug) |
| **Phase 2** | **10+ Indian Languages UI & Voice Synthesis** | • Complete UI translations in frontend for 10+ languages (en, hi, kn, mr, ta, te, ml, gu, pa, bn, or, as, ks).<br>• Dynamic localized crop names (`commodities.local_name`).<br>• Native browser Web Speech Synthesis for all language voice tags (`gu-IN`, `ta-IN`, etc.).<br>• Multi-script regex parser & updated AI prompt.<br>• WhatsApp response templates in all regional languages. | Client-side & backend code only (Zero cost, no new API keys) | High (Core UX & accessibility) |
| **Phase 3** | **Digital India Bhashini AI Integration** | • Connect Bhashini ULCA APIs (`bhashini.gov.in`) for ASR (Speech-to-Text), NMT (Translation), and TTS (Text-to-Speech).<br>• Real WhatsApp voice note interaction (transcribe incoming audio notes, reply with localized text + spoken voice note).<br>• Server-side voice assistant fallback for older mobile devices. | Free registration on `bhashini.gov.in` (`inferenceApiKey`, `userId`) | High (Voice-first rural innovation) |
| **Phase 4** | **e-NAM Platform & Terminal Market Integration** | • Ingest e-NAM daily electronic market feeds for terminal fruit/vegetable trading mandis.<br>• Display trade arrival volumes (quintals/MT) and commodity quality assaying attributes.<br>• "e-NAM Unified Market" badges. | e-NAM open feed / scraper integration | Medium-High (Market depth for fruits & veggies) |
| **Phase 5** | **UPAg Macro-Statistical Advisory** | • Connect UPAg Open API (`data.upag.gov.in/redoc`).<br>• Add "Market Outlook & Seasonal Advisory" widget: State production estimates (surplus/deficit yield forecasts), DoCA retail vs. wholesale margins, and CWWG rainfall/reservoir sowing indices. | UPAg Open API token | Medium (Intelligence & forecasting layer) |
| **Phase 6** | **API Setu Partner Gateway (agricoop / ENAM)** | • Onboard via `partners.apisetu.gov.in`.<br>• GPS nearest APMC lookup (`getNearestApmcDetails`).<br>• Real-time electronic auction bidding data stream (`getBidDetails`). | API Setu Partner Onboarding / Approval | Future / Scalability |
